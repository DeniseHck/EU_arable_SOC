# 🌍 Scalable Earth Engine Pipeline for Soil Property Mapping

This repository demonstrates a geospatial machine learning workflow for mapping soil-related properties using Sentinel-2 imagery and environmental covariates.

## Introduction

This project presents a scalable approach to improving the spatial detail and predictive performance of soil property mapping using optical satellite data combined with auxiliary environmental variables.

The workflow is designed to operate at regional to continental scales and can be adapted to different study areas and target variables.

---

## Method

* Satellite image compositing and quality masking
* Feature engineering from multispectral imagery
* Integration of climatic and topographic datasets
* Machine learning model training within Google Earth Engine
* Spatial prediction over large areas
